# 🌌 POCO M5 HyperOS 3 Super Lockscreen Port v3.0.3

Полноценный порт кастомизации экрана блокировки **HyperOS 3 (Super Lockscreen, Depth Wallpaper 3D, кастомные часы, стили шрифтов и питомцы)** для смартфона **POCO M5 (`rock` / `stone`)** под управлением **HyperOS 1.0 (Android 14)**.

---

## 🚀 Что нового в версии v3.0.3 / Changelog

- 🕒 **Решена проблема с применением кастомных часов:**
  - Внедрен двусторонний транслятор шаблонов между HyperOS 3 и HyperOS 1 SystemUI.
  - Все шаблоны из вкладок **«Классика»**, **«Журнал»**, **«Большие цифры»**, **«Искусство»** и **«Питомцы»** теперь стабильно и корректно накладываются на экран блокировки POCO M5.
- 🔄 **Двойная синхронизация настроек:**
  - `TemplateApiImpl.writeTemplateInfo` синхронно пишет в `constant_template_editor_info` и `constant_lockscreen_info`, уведомляя системный `ContentObserver` через `notifyChange`.
- ⚙️ **Обновлены пресеты шаблонов:**
  - 41 файл конфигурации в `assets/config/` переведен на совместимые с рендерером POCO M5 идентификаторы.
- 🖼️ **Эффект глубины 3D и обои:**
  - Сохранена полная поддержка масок глубины для портретных и художественных обоев.
- 🇷🇺 **Русский язык:**
  - Полная русификация всех экранов и диалогов редактора.

---

## 📦 Установка

1. Скачайте архив **`POCO_M5_HyperOS3_Lockscreen_Port-v3.0.3.zip`** ниже.
2. Откройте **KernelSU** / **Magisk** / **APatch**.
3. Установите модуль из хранилища и перезагрузите телефон.
4. Удерживайте палец на экране блокировки 1–2 секунды для открытия редактора.
