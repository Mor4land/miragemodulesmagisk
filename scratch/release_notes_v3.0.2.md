# HyperOS 3 Super Lockscreen & Depth Wallpaper Port for POCO M5 (rock)
**Версия: v3.0.2-HyperOS1**  
**Совместимость: POCO M5 (rock / stone, Helio G99), HyperOS 1.0 (Android 14, API 34), Root (Magisk / KernelSU / APatch)**

### Что исправлено и реализовано в v3.0.2:
1. **Устранение краша `ClassNotFoundException: com.miui.kg.editor.EditorApplication`**:
   - Вшит класс-адаптер `Lcom/miui/kg/editor/EditorApplication;` напрямую в `classes.dex`, наследующий `com.miui.aod.AODApplication`. Решена несовместимость с базой PackageManagerService на стоковых прошивках HyperOS 1.0.
2. **Изоляция и маскировка стокового OAT (`/product/priv-app/MIUIAod/oat`)**:
   - В `post-fs-data.sh` и `service.sh` интегрировано монтирование чистой `tmpfs` поверх стокового каталога `oat`, что исключает попытки ART запускать устаревший стоковый `.odex`.
3. **Разблокировка вызова Редактора (`isMiuiCall` Patch)**:
   - Снято ограничение белого списка вызывающих пакетов — теперь полноэкранный редактор кастомизации открывается как по долгому тапу на экране блокировки через SystemUI, так и из настроек ("Темы / Обои и персонализация") и сторонних лаунчеров.
4. **Все 5 категорий стилей и циферблатов разблокированы**:
   - Классика (`Classic`), Журнал (`Magazine`), Ромб/Художественный (`Rhone`), Питомцы (`04_pets` со всеми 9 3D-масками глубины), Восточное искусство (`Eastern Art`).
5. **Полная русская локализация интерфейса**:
   - Кнопки управления ("Обои", "ИИ", "Глубина", "Эффекты", "Применить", "Отмена") полностью русифицированы.
6. **IPS LCD Display Optimization**:
   - Интегрирован пересобранный оверлей `ElderlyNavigationBarOverlay` (minSdkVersion 33) для корректной работы пробуждения и отсутствия фантомного выгорания.

### Инструкция по установке:
1. Скачайте `POCO_M5_HyperOS3_Lockscreen_Port-v3.0.2.zip`.
2. Прошейте модуль в **KernelSU**, **Magisk** или **APatch**.
3. Перезагрузите устройство.
4. На заблокированном экране зажмите пальцем свободную область (либо перейдите в Настройки -> Обои и персонализация) — откроется полноэкранный редактор HyperOS 3!
